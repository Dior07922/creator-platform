# 支付宝支付接入

当前项目已接入支付宝电脑网站支付流程：创建订单、生成支付宝收银台地址、异步通知验签、主动查询交易状态，以及支付成功后发放兑换码。

## 需要在支付宝开放平台完成

1. 创建网页/移动应用，并添加适合当前网站的支付能力。
2. 配置 RSA2 接口加签。项目支持普通公钥模式，默认按 PKCS8 应用私钥读取。
3. 在沙箱完成联调后，再提交应用审核并切换正式网关。
4. 正式环境必须提供公网 HTTPS 地址，支付宝服务器无法回调 `localhost`。

## 本地配置

复制 `.env.local.example` 中的支付宝变量名到 `.env.local`，由项目所有者本人填写真实值：

- `ALIPAY_APP_ID`：应用 ID。
- `ALIPAY_PRIVATE_KEY`：应用私钥，仅保存在服务端。
- `ALIPAY_PUBLIC_KEY`：支付宝公钥，不是应用公钥。
- `ALIPAY_KEY_TYPE`：支付宝密钥工具默认生成时通常填写 `PKCS8`。
- `ALIPAY_GATEWAY`：沙箱联调时填写开放平台当前提供的沙箱网关；留空使用正式网关。
- `ALIPAY_SELLER_ID`：可选。填写后，异步通知会同时核对收款方 ID。
- `APP_BASE_URL`：已部署网站的公网 HTTPS 根地址。
- `ALIPAY_NOTIFY_URL`：可选。需要单独指定异步通知地址时填写。

不要把密钥写入 `NEXT_PUBLIC_` 变量，也不要提交 `.env.local`。

## 安全边界

- 浏览器只得到支付宝收银台地址，私钥不会发送到前端。
- 订单金额取自服务端已经保存的订单，不接受浏览器在发起支付时重新传价。
- 只有通过支付宝签名、应用 ID、订单号和金额核验的成功通知，或支付宝主动查询确认成功后，订单才会标记为已支付。
- 未支付订单不能领取兑换码；重复交付会返回同一兑换码。
- 微信支付尚未接入，界面中保持不可选，避免形成假支付。
