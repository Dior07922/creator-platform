## 已接入

### 阿里云短信

- 用途：苒境商城手机号验证码注册与登录
- 项目接口：`POST /api/auth/sms/send`
- 服务端调用：阿里云短信 `SendSms`，API 版本 `2017-05-25`
- 短信模板：`SMS_512275103`
- 模板变量：`code`
- 环境变量：`ALIYUN_SMS_ACCESS_KEY_ID`、`ALIYUN_SMS_ACCESS_KEY_SECRET`、`ALIYUN_SMS_SIGN_NAME`、`ALIYUN_SMS_TEMPLATE_CODE`
- 其他身份变量：`AUTH_SECRET`（用于验证码摘要和安全限流，不得提交原值）
- 权限要求：RAM 策略 `RanjingSmsSendOnly`，不得改为 FullAccess
- 状态：Next.js API Route 已在本地真实运行并验证；未登录 `/api/auth/me` 返回 401，未配置密钥时 `/api/auth/sms/send` 返回 503。当前本地与 Vercel 环境变量尚未配置，因此真实发送测试仍为“外部服务待配置/待生效”。
- 安全规则：AccessKey 只在服务端读取，不进入 React、不返回前端、不打印完整值
